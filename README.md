A beginner Cisco Packet Tracer project demonstrating a small office LAN, IP addressing and connectivity testing.

# Small Office Network

## Project Overview
This project demonstrates a basic Local Area Network (LAN)
designed using Cisco Packet Tracer.

## Objectives
- Connect multiple computers using a switch.
- Configure static IP addresses.
- Understand subnet masks.
- Test connectivity between devices.

## Tools Used
- Cisco Packet Tracer

## IP Addressing

| Device | IP Address |
|---|---|
| PC0 | 192.168.1.10 |
| PC1 | 192.168.1.11 |
| PC2 | 192.168.1.12 |
| PC3 | 192.168.1.13 |
| Printer | 192.168.1.20 |

## Testing
Connectivity was tested using the ping command.

## What I Learned
- How devices communicate in a LAN.
- How to assign static IP addresses.
- How to test network connectivity.
